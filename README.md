# X-Manager Lite

Русское терминальное меню для сетевых служб на **Debian 12/13 amd64 с systemd**.
Самостоятельная редакция X-Manager: Snell v5/v6, Mieru, MasterDnsVPN,
локальные подписки TUNA, watchdog и настройки сервера.

| Раздел | Что делает Lite |
|---|---|
| Snell | Устанавливает v5; позволяет создать и активировать v6. Одновременно работает одна версия. Настройки и общий ключ сохраняются раздельно |
| Mieru | Установка mita, пользователи, порты, имя, паттерн и обфускация, маршрутизация, ссылки и QR |
| MasterDNS | Установка после указания своей DNS-зоны; параметры туннеля, ключ, ссылки, Direct/SOCKS5, доступ и журналы |
| qWDTT / CSQTT | Управление **существующими установками**: состояние, доступ, реквизиты, ссылки, запуск и остановка. Их ядра Lite не устанавливает |
| Подписки | Пользователи, отдельные и внешние ссылки, токены, группы URL-test/Speedtest, локальный HTTP API |
| Watchdog | Ограниченный аварийный перезапуск и отдельные локальные проверки зависания; соблюдает ручное отключение |
| Оптимизация | Адаптивный BBR/fq, буферы и conntrack; дополнительные TCP-параметры по выбору; DNS, swap, fail2ban, расписание перезагрузки |
| Обслуживание | Выпуск Lite с фиксированными компонентами, проверка SHA-256, резервное копирование, откат |

OpenFlux, WebDAV, Volga, CottenDNS и отдельный QUIC Proxy не устанавливаются.
Форматы внешних ссылок и контейнеров в сервере подписок сохранены; возможность
импортировать конкретный протокол зависит от клиента.

## Установка одной командой

От `root`, при наличии `curl` и `python3`:

```bash
bash -c 'set -euo pipefail; f=$(mktemp); trap "rm -f -- \"$f\"" EXIT; curl -fL --proto "=https" --proto-redir "=https" https://github.com/lesovoi53/x-manager-lite/releases/latest/download/quick-start.sh -o "$f"; bash "$f" --quick'
```

`--quick` использует существующий Xray: поддерживаемую локальную базу X-UI
либо обнаруженные совместимые шлюзы standalone Xray. Сам Xray не устанавливается.
Для сервера **без Xray** замените последний `--quick` на **`--direct`**.
Новые порты проверяются на занятость; 443 и 8443 исключены.

Lite не заменяет установленный полный X-Manager: при его обнаружении установка
останавливается до изменения его файлов. Автоматической миграции Full → Lite нет.

После установки: `x-manager-lite` или `x-manager`.

```text
X-MANAGER LITE / Главная
 [1] Snell v5 / v6                 состояние обеих версий
 [2] Mieru                        состояние
 [3] MasterDNS                    состояние
 [4] qWDTT                        состояние
 [5] CSQTT                        состояние
 [6] Пользователи и подписки
 [7] Watchdog
 [8] Сеть и оптимизация
 [9] Обновление и обслуживание
 [0] Выход
```

## Обновление и откат

Обновление: **[9] → [1]**. Загружается последний опубликованный обычный Release
из `lesovoi53/x-manager-lite`, а не произвольное состояние ветки `main`.
Версии и хеши компонентов закреплены в `components.json`.

Резервная копия: **[9] → [2]**. Восстановление: **[9] → [3]**.
Каталог `/var/backups/x-manager-*` закрыт правами `0700` и содержит секреты:
его нельзя публиковать. Перед откатом создаётся новая копия текущего состояния.
