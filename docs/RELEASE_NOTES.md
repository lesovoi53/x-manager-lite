# Изменения X-Manager Lite

## v2026.10.23.1 — MasterDNS: домены и параметры подключения

Версии и SHA-256 ядер Snell v5/v6, Mieru и MasterDnsVPN сохранены.
Выпуск обновляет меню и вспомогательные скрипты управления MasterDNS.

- Одна служба MasterDNS обслуживает 1–16 доменов. Меню позволяет добавлять,
  удалять и выбирать первый домен. Изменения остаются черновиком до сохранения;
  последний домен удалить нельзя. Префикс `d.` автоматически не добавляется.
- Экспорт StormDNS создаёт отдельную `stormdns://` ссылку для каждого домена.
  Экспорт TUNA создаёт одну `tuna://` ссылку с полным списком доменов в одном
  профиле. Выбранные настройки профиля одинаковы в обоих форматах.
- В параметрах подключения доступны шесть методов шифрования нативного ядра:
  `0 NONE`, `1 XOR`, `2 ChaCha20`, `3 AES-128-GCM`, `4 AES-192-GCM`,
  `5 AES-256-GCM`. Совместимый ключ сохраняется; несовместимый заменяется только
  после явного согласия. Метод и ключ применяются вместе, с восстановлением
  прежних файлов и активного состояния при ошибке. Обновление самого меню
  не меняет метод шифрования или ключ.
- Для новых ссылок общие значения по умолчанию трёх профилей:
  `resolver_balancing_strategy=5` (Hybrid Score), `upload_compression_type=2`
  и `download_compression_type=2` (LZ4), `rx_tx_workers=16`,
  `tunnel_process_workers=0` (выбор ядра). Остальные различия профилей сохранены.
- Редактор экспортируемых профилей содержит 21 параметр: резолверы,
  балансировку, дублирование данных и подключения, сжатие обоих направлений,
  рабочие потоки, границы MTU, ARQ, четыре интервала ping, размер пачки и
  Base64-кодирование данных. Просмотр, редактирование и сброс работают с
  черновиком; запись выполняется отдельным действием «Сохранить».
  Настройки остальных профилей сохраняются.

Локальный `client_link_profiles.json` создаётся только при явном сохранении,
с правами `0600`; запись атомарная и проверяет внешние изменения. Повреждённый
файл блокирует экспорт вместо скрытого сброса. Редактор профилей не перезапускает
службу. Уже выданные ссылки, подписки и параметры сохранённых клиентов
автоматически не переписываются.

Штатное обновление выполняется через **[9] → [1]** из опубликованного Release.
Основной установщик сохраняет существующие домены, серверные параметры, ключи,
пользователей и настройки профилей. Повторная установка MasterDNS без аргументов
также сохраняет массив доменов; позиционные аргументы явно заменяют весь список.
Остановленные службы и ограничения запуска сохраняются.

Подробное поведение и команды проверок описаны в
[руководстве MasterDNS](masterdns-domains.md).
[История проверок](VALIDATION.md) относится к указанным в ней прежним выпускам;
она не является приёмкой этого обновления. Проверка обновления рабочего VPS,
подключения клиента и длительной работы этого выпуска на момент подготовки
заметки ещё не завершена.
