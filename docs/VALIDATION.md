# Проверки первого выпуска Lite

Проверки выполнялись 13 октября 2026 года в отдельных локальных QEMU/KVM VM.
Это не проверка на рабочих VPS пользователя и не приёмка мобильного клиента.

| Проверка | Результат |
|---|---|
| Чистая установка Debian 12.15 amd64/systemd | Успешно, Snell/Mieru/TUNA запущены |
| Чистая установка Debian 13.7 amd64/systemd | Успешно, Snell/Mieru/TUNA запущены |
| Основные регрессионные тесты | 310 на каждой системе |
| Сервер подписок, группы, URI и родной кодек Mieru | Основной набор включает Mieru; отдельный набор TUNA — 99 тестов на каждой системе |
| Повторная установка | Конфиги и запись пользователя сохранены; ручной stop Mieru сохранён |
| Нет локального asset | Ошибка до замены управляемых файлов; данные и службы сохранены |
| Подставленная неисправная служба Mieru | Обновление не объявляет успех; рабочая версия и данные восстановлены |
| TCP-профиль | Просмотр без записи, реальное применение, откат, конфликты/частичный сбой в unit-тестах |
| MasterDNS | Установка и active-служба; сохранён системный DNS-resolver, выбран свободный адрес UDP/53 |
| Snell v5 → v6 → v5 | Реальное переключение и авторизованный HTTPS-запрос |
| Snell v6 в TUNA | Локальная ссылка опубликована; повторная публикация не дублирует её |
| Обновление с активной v6 | v6 остаётся активной, v5 остановленной, пользователь и конфиги сохранены |
| Crash-watchdog | На искусственной службе: первый запуск + 5 повторов, затем блокировка |
| Автосброс | Реальный таймер восстановил тестовую службу через 306 секунд; ручной stop соблюдён |
| Защита редакции | Full не принимается установщиком и updater Lite |
| Ручной откат | Восстановлены файлы, значения TCP в ядре и работающие Snell/Mieru/MasterDNS/TUNA |

## Границы проверки

- Установка и обновление выполнялись с Direct-маршрутом в локальных VM.
  Обнаружение Xray, интеграция совместимой базы панели, SOCKS/TPROXY и сохранение
  правил покрыты унаследованными изолированными тестами. Любая произвольная
  панель, контейнерная схема либо fork Xray не считается автоматически проверенной.
- Реальный мобильный импорт и трафик qWDTT/CSQTT/Mieru/DNS на внешнем устройстве
  в этой задаче не проверялись. Синтетическая аварийная `csqtt.service` проверяла
  watchdog, а не реализацию протокола CSQTT.
- Для MasterDNS не проверялось внешнее DNS-делегирование. Создание службой
  слушателя само по себе не доказывает доступность зоны с телефона.
- TCP-проверка Snell не считается проверкой удалённого UDP-реле.
- Длительная нагрузка, многосуточное восстановление, провайдерский firewall,
  NAT и работа через конкретного внешнего агрегатора требуют отдельной приёмки.

Воспроизведение и ограничения лабораторных скриптов: [DEVELOPMENT.md](DEVELOPMENT.md).
